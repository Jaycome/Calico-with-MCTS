# Resume Positioning

This project should be positioned as an AI search and simulation project rather than as a generic board game clone.

## Recommended Resume Title

**Calico AI Agent — Monte Carlo Tree Search for Game Decision-Making**

## Resume Bullets

- Implemented Monte Carlo Tree Search agents to model decision-making in a non-deterministic board game environment.
- Compared MCTS variants under different time budgets and exploration-exploitation settings to evaluate agent performance and decision stability.
- Structured game-state representation, legal move generation, and simulation workflows to support reproducible AI agent evaluation.

## Best Use in Portfolio

Use this project as a supporting AI fundamentals project. It should not be the first project in a resume targeting enterprise software or AI application roles, but it can strengthen evidence of algorithmic reasoning, search, and simulation experience.
